This is a Desktop app, that have the following features:
Per-process network monitoring — upload/download bytes for Chrome, Edge, Firefox, Telegram, VS Code, etc.
Website/domain monitoring — domains contacted and traffic attributed to them.
Optional browser extension — gives much better URL/page-level visibility.
Network connection monitoring — remote IP, port, protocol, process.
Historical database — hourly/daily/monthly statistics.
Storage analyzer — disk usage by drive, folder, file type and application.
Large-file detection — identify files consuming significant space.
Duplicate-file detection — optional SHA-256 hashing.
Real-time dashboard — current network and disk activity.
Reports/export — CSV/JSON/Excel.
Alerts — application/domain exceeds a bandwidth threshold.
Windows startup/background service.
Low-resource operation so the monitor itself doesn't consume significant CPU/RAM
